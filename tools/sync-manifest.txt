# What tools/sync-from-windows.ps1 can and cannot cover.
#
# Sections:
#   [adapted]  files this port changed on purpose (platform seams, paths, translations).
#              The sync tool never resolves a conflict in these by itself: it stops,
#              names the file and leaves the patch for a human decision.
#   [rewrite]  files that can be taken from the Windows side wholesale as long as the
#              Windows paths in them are rewritten to the Linux ones below.
#
# Everything that is not listed here is applied as-is: new files (no conflict possible)
# and files that are byte-identical to the Windows baseline.
